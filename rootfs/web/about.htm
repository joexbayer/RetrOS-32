RetrOS-32 is a small 32-bit OS built for learning, experimentation, and fun.

The web server lives in: apps/webserver/webserv.cpp

Key Pieces
  • Kernel: Custom RetrOS-32
  • Network: Minimal TCP/IP stack
  • Web: Lightweight HTTP handler (apps/utils/Web)
